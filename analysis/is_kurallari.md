# İş Kuralları

| ID | İş Kuralı |
|----|------------|
| RULE-01 | Her ürün sisteme yalnızca bir kez ürün kabul işlemi ile kaydedilebilir. |
| RULE-02 | Ürün kabulü tamamlanmadan ürün rafa yerleştirilemez. |
| RULE-03 | Stok miktarı hiçbir durumda negatif olamaz. |
| RULE-04 | Sipariş, stokta yeterli ürün bulunuyorsa hazırlanabilir. |
| RULE-05 | Sevkiyat işlemi tamamlanan sipariş tekrar "Hazırlanıyor" durumuna alınamaz. |
| RULE-06 | İade işlemi yalnızca daha önce sevk edilmiş ürünler için başlatılabilir. |
| RULE-07 | Her kullanıcı yalnızca yetkili olduğu işlemleri gerçekleştirebilir. |
| RULE-08 | Silinen kayıtlar sistemden tamamen kaldırılmamalı, pasif duruma getirilmelidir. |
| RULE-09 | Her stok hareketi tarih, saat ve işlemi yapan kullanıcı bilgisi ile kayıt altına alınmalıdır. |
| RULE-10 | Barkod numarası sistem içerisinde benzersiz olmalıdır. |
