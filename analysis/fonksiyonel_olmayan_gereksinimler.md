# Fonksiyonel Olmayan Gereksinimler

| ID | Gereksinim |
|----|------------|
| NFR-01 | Sistem kullanıcı dostu ve kolay kullanılabilir bir arayüze sahip olmalıdır. |
| NFR-02 | Yetkisiz kullanıcıların sisteme erişimi engellenmelidir. |
| NFR-03 | Kullanıcı işlemleri kayıt altına alınmalıdır. |
| NFR-04 | Sistem, aynı anda birden fazla kullanıcının işlem yapmasını desteklemelidir. |
| NFR-05 | Sayfa geçişleri ve temel işlemler kabul edilebilir sürelerde tamamlanmalıdır. |
| NFR-06 | Sistem, veri bütünlüğünü koruyacak şekilde çalışmalıdır. |
| NFR-07 | Veriler düzenli olarak yedeklenebilmelidir. |
| NFR-08 | Sistem, hata durumlarında kullanıcıya anlaşılır bilgilendirme mesajları göstermelidir. |
