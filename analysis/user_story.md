# User Story

| ID | User Story | Kabul Kriterleri |
|----|------------|------------------|
| US-01 | Depo personeli olarak, ürün kabul kaydı oluşturabilmek istiyorum. Böylece depoya gelen ürünleri sisteme kaydedebilirim. | Ürün bilgileri eksiksiz girildiğinde kayıt oluşturulmalıdır. |
| US-02 | Depo personeli olarak, ürünleri barkod ile aratabilmek istiyorum. Böylece ürünlere hızlıca ulaşabilirim. | Geçerli barkod okutulduğunda ürün bilgileri görüntülenmelidir. |
| US-03 | Depo yöneticisi olarak, güncel stok durumunu görüntülemek istiyorum. Böylece stok seviyelerini takip edebilirim. | Stok miktarları güncel olarak listelenmelidir. |
| US-04 | Depo personeli olarak, sipariş toplama listesine erişmek istiyorum. Böylece siparişleri eksiksiz hazırlayabilirim. | Bekleyen siparişler listelenmelidir. |
| US-05 | Sistem yöneticisi olarak, kullanıcı yetkilerini yönetmek istiyorum. Böylece kullanıcıların erişimlerini kontrol edebilirim. | Yetki değişiklikleri sisteme kaydedilmelidir. |
