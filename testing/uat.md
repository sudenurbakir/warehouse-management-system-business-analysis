# User Acceptance Test (UAT)

## Amaç

Bu doküman, Warehouse Management System (WMS) projesinin iş gereksinimlerini karşılayıp karşılamadığını doğrulamak amacıyla gerçekleştirilen Kullanıcı Kabul Testi (User Acceptance Test - UAT) sonuçlarını içermektedir.

---

## UAT Sonuçları

| UAT No | İşlev | Beklenen Sonuç | Gerçek Sonuç | Durum |
|---------|--------|----------------|--------------|-------|
| UAT-01 | Yeni ürün oluşturma | Ürün başarıyla oluşturulmalıdır. | Beklenen şekilde çalıştı. | ✅ Başarılı |
| UAT-02 | Ürün bilgilerini güncelleme | Güncellenen bilgiler kaydedilmelidir. | Beklenen şekilde çalıştı. | ✅ Başarılı |
| UAT-03 | Ürün silme | Ürün sistemden kaldırılmalıdır. | Beklenen şekilde çalıştı. | ✅ Başarılı |
| UAT-04 | Stok güncelleme | Güncel stok miktarı görüntülenmelidir. | Beklenen şekilde çalıştı. | ✅ Başarılı |
| UAT-05 | Sipariş oluşturma | Yeni sipariş başarıyla oluşturulmalıdır. | Beklenen şekilde çalıştı. | ✅ Başarılı |
| UAT-06 | Sipariş durumu güncelleme | Sipariş durumu güncellenmelidir. | Beklenen şekilde çalıştı. | ✅ Başarılı |

---

## UAT Onayı

Yapılan kullanıcı kabul testleri sonucunda sistemin tanımlanan iş gereksinimlerini karşıladığı görülmüş ve uygulamanın kullanıma uygun olduğu değerlendirilmiştir.
