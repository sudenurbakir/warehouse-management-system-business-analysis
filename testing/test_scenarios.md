# Test Senaryoları

## Amaç

Bu doküman, Warehouse Management System (WMS) projesindeki temel iş süreçlerinin doğruluğunu kontrol etmek amacıyla hazırlanan test senaryolarını içermektedir.

| Test No | Senaryo | Beklenen Sonuç |
|----------|----------|----------------|
| TS-01 | Sisteme yeni ürün eklenir. | Ürün başarıyla oluşturulmalıdır. |
| TS-02 | Mevcut ürün bilgisi güncellenir. | Ürün bilgileri başarıyla güncellenmelidir. |
| TS-03 | Ürün silinir. | Ürün sistemden kaldırılmalıdır. |
| TS-04 | Stok miktarı güncellenir. | Yeni stok miktarı doğru görüntülenmelidir. |
| TS-05 | Tüm ürünler listelenir. | Ürün listesi eksiksiz görüntülenmelidir. |
| TS-06 | Sipariş oluşturulur. | Sipariş başarıyla kaydedilmelidir. |
| TS-07 | Sipariş durumu güncellenir. | Güncel sipariş durumu görüntülenmelidir. |
| TS-08 | Geçersiz ürün bilgisi ile kayıt oluşturulmaya çalışılır. | Sistem uygun hata mesajı göstermelidir. |
